Privacy Terms

Private, owner-operated backup utility

Encrypted backups, stored with narrow Google Drive access.

Property Operations Backup creates encrypted recovery archives and stores them in a dedicated Google Drive folder controlled by the operator.

Google permission drive.file

The application can work only with Drive files and folders that it creates or that are explicitly made available to it. It does not request access to the rest of the account’s Drive.

How it works

A deliberately small access boundary

  1. CaptureThe authorized backup process prepares a recovery archive.
  2. EncryptThe archive is encrypted locally before it leaves the backup host.
  3. StoreOnly encrypted backup files are uploaded to the dedicated Drive folder.
  4. VerifyUploaded ciphertext is checked for integrity and retained under the configured backup policy.

Operating principles

Built for recovery, not data collection

Least privilege

The application requests only the non-sensitive drive.file scope.

Encrypted first

Property Operations data is encrypted before upload. Recovery keys are kept outside Google Drive.

No advertising

Google user data is not sold, shared for advertising, or used to build advertising profiles.
